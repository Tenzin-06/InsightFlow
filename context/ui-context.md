# 🧭 Design Language Rules

| Rule           | Description                                          |
| -------------- | ---------------------------------------------------- |
| Visual Density | Keep layouts spacious and breathable                 |
| Card Styling   | Prefer soft shadows over heavy borders               |
| Contrast       | Use low-contrast surfaces with strong text hierarchy |
| AI Features    | Use teal accents sparingly for intelligence cues     |
| Dashboard Feel | Clean SaaS + research-grade professionalism          |
| Motion         | Minimal and subtle transitions only                  |
| Charts         | Prioritize readability over decoration               |
| Backgrounds    | Avoid pure white (#FFFFFF) for full-page backgrounds |

---

# 🎯 Overall UI Feel

InsightFlow should feel like:

- an intelligent research workspace
- calm and trustworthy
- modern but not futuristic
- data-centric
- clean enterprise SaaS
- AI-assisted rather than AI-overwhelming
- suitable for universities, researchers, and government agencies
